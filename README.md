# 라운드 타이머

주짓수 도장에서 쓰는 라운드·인터벌 타이머 웹앱입니다.
GitHub Pages에 올리면 아이폰·아이패드·안드로이드에서 **홈 화면에 추가**해서 앱처럼 쓸 수 있고, 한 번 열고 나면 인터넷 없이도 동작합니다.

## 기능

- 준비 → 운동 / 휴식 × 라운드 × 세트, 세트 간 휴식, 쿨다운까지 시간 설정
- 기본 프리셋: 스파링 5분, 스파링 6분, 드릴 3분, 타바타 (자유롭게 수정·추가·삭제)
- 소리 종류 선택: 전자음 / 복싱 벨 / 호루라기 (설정에서 눌러서 미리 듣기)
- 마지막 3초 카운트, 종료 10초 전 알림, 한국어 음성 안내, 구간 전환 시 화면 깜빡임
- 일시정지, 이전·다음 구간 건너뛰기, 가로·세로 화면, 아이패드 큰 화면 대응
- 운동 기록(완료/중단) 저장
- 화면이 꺼졌다 켜져도 실제 흐른 시간에 맞춰 이어짐

## 배포 (GitHub Pages)

1. GitHub에 새 저장소를 만들고 이 폴더 내용을 그대로 올립니다.
2. 저장소 **Settings → Pages**에서 Source를 **Deploy from a branch**, 브랜치를 **main / (root)** 로 설정합니다.
3. 잠시 뒤 `https://<아이디>.github.io/<저장소이름>/` 주소로 열립니다.

## 설치 (홈 화면에 추가)

- **아이폰·아이패드:** Safari로 위 주소 열기 → 공유 버튼 → **홈 화면에 추가**
- **안드로이드:** Chrome으로 열기 → 메뉴 → **앱 설치** 또는 **홈 화면에 추가**

관장님 기기에도 주소만 보내면 같은 방법으로 설치할 수 있습니다. 계정은 필요 없습니다.

## 업데이트

파일을 고친 뒤 `sw.js`의 `VERSION` 값을 올리고 push 하세요 (예: `"v1"` → `"v2"`).
기기에서는 앱을 한두 번 껐다 켜면 새 버전이 적용됩니다.

## 알아둘 점

- 운동 목록과 기록은 **기기마다 따로** 저장됩니다. 앱(홈 화면 아이콘)을 지우면 함께 지워집니다.
- 화면이 꺼져 있는 동안에는 소리 안내가 나오지 않습니다. 도장에서는 자동 잠금을 길게 해두세요.
- 기기가 무음 모드면 효과음이 안 들릴 수 있습니다.
